# Vault для Windows

Официальные сборки VPN-клиента **Vault** для компьютеров на Windows.

**[⬇ Скачать последнюю версию](https://github.com/vault-apps/windows/releases/latest)**

## Установка

1. Откройте [страницу последнего релиза](https://github.com/vault-apps/windows/releases/latest) и скачайте файл `VaultSetup-<версия>.exe`.
2. Запустите установщик и разрешите изменения в окне контроля учётных записей (UAC). Права администратора нужны один раз — чтобы установить службу VPN; само приложение работает без них.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.
4. Запустите Vault и войдите по ссылке доступа, по почте или через Telegram. Ссылку доступа можно получить в [личном кабинете](https://lk.vault-app.ru) или в Telegram-боте [@vault_vpnbot](https://t.me/vault_vpnbot).

**Требования:** Windows 10 или 11, 64-бит. Нужен компонент Microsoft Edge WebView2 — в Windows 11 и обновлённой Windows 10 он уже есть; если его нет, установщик предложит его скачать.

## Как пользоваться

- Vault запускается вместе с Windows и сворачивается в трей (значок рядом с часами). Отключить можно в **Настройки → Автозапуск**.
- Крестик окна сворачивает Vault в трей — VPN продолжает работать. Чтобы выключить VPN и закрыть приложение, нажмите на значок в трее правой кнопкой → **Выйти**.

## Обновления

Vault обновляется сам: при запуске приложение проверяет новые релизы в этом репозитории и предлагает скачать и установить обновление. Проверить вручную можно в **Настройки → О приложении → Проверить обновления**. Новая версия ставится поверх прежней, входить заново не нужно.

## Подлинность

Скачивайте Vault только со [страницы релизов](https://github.com/vault-apps/windows/releases) этого репозитория. В описании каждого релиза указана контрольная сумма SHA-256 установщика — сверьте её со скачанным файлом в PowerShell:

```
Get-FileHash .\VaultSetup-<версия>.exe -Algorithm SHA256
```

## Удаление

**Параметры → Приложения → Установленные приложения → Vault → Удалить.** Вместе с приложением удаляется и служба VPN.

## Поддержка

- Личный кабинет: [lk.vault-app.ru](https://lk.vault-app.ru)

Если что-то не работает, сохраните журнал: **Настройки → Диагностика → Сохранить логи** (или «Проблемы со входом? Сохранить логи для поддержки» на экране входа) — архив появится в папке «Загрузки». Отправьте его в поддержку: ключи серверов и данные входа в журнал не попадают.
